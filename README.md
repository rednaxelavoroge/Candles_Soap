# Candles_Soap

Фото товаров для сайта: гипс, свечи, мыло.

## Как разложены файлы

| Что | Где | В гите |
|-----|-----|--------|
| Оригиналы с Яндекс.Диска | `content/raw/<категория>/` | нет, в `.gitignore` |
| Веб-версии (WebP) | `public/catalog/<категория>/` | да |

Категории: `gypsum`, `candles`, `soap`. Структура вложенных папок с Диска сохраняется в обоих деревьях.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

.venv/bin/python scripts/fetch_catalog.py             # все три категории
.venv/bin/python scripts/fetch_catalog.py --only свечи # одна категория
.venv/bin/python scripts/fetch_catalog.py --report     # статистика по скачанному
```

Скрипт идемпотентен: уже скачанные файлы (совпадает размер) пропускаются, WebP пересобирается
только если оригинал новее. Прогон можно прерывать и запускать заново.

## Что делает скрипт

- рекурсивно обходит публичные папки Яндекс.Диска через `cloud-api.yandex.net` (без авторизации),
  разворачивая пагинацию по 200 элементов;
- скачивает оригиналы в `content/raw/`, сохраняя структуру папок;
- для изображений делает веб-версию: поворот по EXIF, длинная сторона максимум 1600px
  (меньшие не растягиваются), WebP качество 82; прозрачность сохраняется;
- HEIC/HEIF с айфона обрабатываются через `pillow-heif`;
- видео (`.mp4`, `.mov`, ...) только скачиваются, без конвертации;
- битый файл логируется и не роняет прогон.

## Требуется доступ в сеть

Скрипту нужны хосты `cloud-api.yandex.net` и `downloader.disk.yandex.ru`.
