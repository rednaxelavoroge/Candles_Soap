# Candles_Soap

Сайт-каталог изделий ручной работы Анны Манасарян: свечи, мыло, гипс, декор.
Прототип для показа заказчику — кликабельный сайт, не макет.

## Стек

Next.js 15 (App Router, TypeScript) · Tailwind CSS v4 · Framer Motion · Lenis · next/image.
CMS нет: контент лежит в `src/data/*.json` и разбирается zod-схемами.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # продакшен-сборка, все страницы пререндерятся статически
npm run typecheck
```

## Структура

```
src/data/          контент: categories, tags, products, site
src/lib/schemas.ts zod-схемы — единственное описание формы данных
src/lib/content.ts единственная точка чтения контента
src/components/    ui/ — переиспользуемое, home/ — блоки главной
tools/ingest.mjs   загрузка и обработка изображений со старого сайта
```

### Замена источника данных на REST

Компоненты не импортируют JSON напрямую — только функции из `src/lib/content.ts`.
Чтобы перейти на API, переписывается один этот модуль: схемы и типы остаются,
ни один компонент не меняется.

## Модель данных

- `categories.json` — 8 категорий: `candles`, `soap`, `gypsum`, `sachet`,
  `holders`, `boxes`, `plates`, `decor`.
- `tags.json` — теги двух групп: `occasion` (повод) и `recipient` (адресат).
- `products.json` — у товара ровно одна категория и сколько угодно тегов.

Плоский список из 38 разделов заказчицы раскладывается на эту пару осей:
то, что было отдельным разделом («новогодние свечи», «мыло для мужчин»),
собирается фильтрами категория + теги.

## Контент

Изображения готовит `tools/ingest.mjs`: тянет страницы из `tools/sources.json`,
собирает ссылки из `src`, `srcset` и ленивых `data-`атрибутов, ужимает до 1600px
по длинной стороне, конвертирует в WebP, снимает blur-плейсхолдеры и раскладывает
в `public/catalog/<категория>/`.

```bash
NODE_USE_ENV_PROXY=1 npm run ingest
```

Скрипт пишет черновой `tools/ingest-manifest.json` с разбивкой по 3–5 изображений
на товар. Названия и описания скрипт не выдумывает — они проставляются вручную
по манифесту, когда изображения уже можно посмотреть, и переносятся
в `src/data/products.json`.

## Анимация

Ключевой эффект — расходящиеся половины экрана (`src/components/home/SplitReveal.tsx`).
Источник анимации — прогресс скролла (`useScroll` + `useTransform`), а не `mousemove`,
поэтому эффект одинаково работает на десктопе и на телефоне. Курсорный параллакс
добавляется поверх только на устройствах с точным указателем и ограничен 8px.

Анимируются исключительно `transform` и `opacity`. При `prefers-reduced-motion`
секция становится обычной статической, а Lenis не инициализируется.
